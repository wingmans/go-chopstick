# Repository Instructions

## Markdown Width

Keep Markdown source lines at a maximum of 80 characters. This is the default
for all documentation and notes in this repository, including future edits.

Longer lines are exceptions, not the rule. Use them only when wrapping would
damage a table, URL, code block, command, or another fixed-format example.

When adding or updating prose, wrap it to 80 columns before finishing the
change.
